## 4. 状态说明

阶段 5 后，当前代码实际支持的 `POI` 状态为：

- `DRAFT`
- `SUBMITTED`
- `APPROVED`
- `REJECTED`
- `RESUBMITTED`
- `DISPUTING`
- `ARBITRATING`
- `FINALIZED`

含义补充：

- `DISPUTING`：争议处理中
- `ARBITRATING`：等待管理员最终裁定
- `FINALIZED`：已形成最终结论

## 7. 验收路径

### 7.1 采集者验收

1. 使用 `collector / 123456` 登录移动端
2. 打开一条 `REJECTED` 记录
3. 点击“发起异议”
4. 填写说明并提交
5. 记录应进入 `DISPUTING`

### 7.2 核验者验收

1. 使用 `verifier / 123456` 登录移动端或管理端
2. 进入“争议处理”
3. 查看争议详情
4. 提交补充说明
5. 再执行升级
6. 状态应进入 `ARBITRATING`

### 7.3 管理员验收

1. 使用 `admin / 123456` 登录管理端
2. 进入“争议处理中心”
3. 打开 `ARBITRATING` 的争议单
4. 进入“最终裁定处理”
5. 提交裁定结果
6. 状态应变为 `FINALIZED`
7. 页面应展示最终裁定结果
