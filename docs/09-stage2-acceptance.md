# 阶段 2 验收说明

## 1. 阶段目标

阶段 2 的目标是打通 `采集者从移动端创建 POI -> 保存草稿/提交 -> 查看我的 POI -> 管理员查看 POI` 的最小闭环。

## 2. 已完成能力

### 2.1 移动端采集者页面

- 新建 POI 页面
- 拍照/选图
- 定位获取与展示
- POI 分类选择
- 描述填写
- 保存草稿
- 提交待核验
- 我提交的 POI 列表页
- POI 详情页

### 2.2 管理端页面

- POI 列表页
- POI 详情页

### 2.3 后端接口

- POI 分类接口
- 采集者创建 POI 接口
- 采集者更新 POI 接口
- 采集者我的 POI 列表接口
- 采集者 POI 详情接口
- 管理员 POI 列表接口
- 管理员 POI 详情接口

## 3. 当前支持状态

- `DRAFT`
- `SUBMITTED`

对应含义：

- `DRAFT`：草稿，采集者可继续编辑
- `SUBMITTED`：已提交待核验

## 4. 当前最小业务链

1. 采集者登录移动端
2. 新建 POI
3. 拍照或从相册选图
4. 获取当前位置
5. 选择分类并填写描述
6. 保存草稿或提交待核验
7. 在“我提交的 POI”中查看记录
8. 在详情页继续编辑草稿或查看已提交记录
9. 管理员在 Web 后台查看 POI 列表与详情

## 5. 已验证结果

已通过接口和运行环境验证：

- 采集者登录成功
- 上传接口成功
- 创建草稿成功
- 草稿更新为已提交成功
- 采集者 POI 列表查询成功
- 管理员 POI 列表和详情查询成功

## 6. 本阶段实现说明

- 采集图片通过已有上传接口上传
- 当前默认文件策略仍为 `MINIO_FALLBACK_LOCAL`
- 当本机对象存储不可稳定访问时，文件通过后端本地回退 URL 提供访问
- 前端页面保持低保真，但结构已经按后续升级方向拆开

## 7. 本阶段边界

阶段 2 仍未实现：

- 核验者审核流程
- 错误标注与整改
- 地图展示
- 任务派发
- 第三方争议复核

## 8. 进入阶段 3 的前提

进入阶段 3 前，已经具备以下基础：

- POI 主数据已落库
- 采集者能提交待核验数据
- 管理员可查看采集结果
- 上传、鉴权、角色控制和详情查看已稳定
