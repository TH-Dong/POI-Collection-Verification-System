# 阶段 4 验收说明：地图查询与空间辅助能力

## 1. 阶段目标

阶段 4 的目标是补齐 `空间视图` 这一层能力，让核验者和管理员不再只通过表格理解数据，而是可以在地图中查看：

- POI 空间分布
- 问题点位
- 处理进展
- 与列表 / 详情的基础联动
- 导航入口与后续路径规划预留

本阶段优先保证：

- 业务结构先成立
- 角色入口清晰
- 后续可平滑升级成真实地图能力

## 2. 本阶段实际完成内容

### 2.1 管理端

已完成：

- 新增地图页
- 支持按分类、状态、区域筛选
- 支持点位渲染
- 支持错误 / 问题点位特殊标识
- 支持点击点位查看右侧详情
- 支持从 POI 列表跳转地图定位
- 支持从 POI 详情跳转地图定位
- 支持导航入口与路径规划占位

当前说明：

- 管理端已切换为高德 Web 地图底图
- 继续保留原有筛选、联动、点位语义和详情侧栏结构
- 如果缺少 `VITE_AMAP_WEB_KEY`，页面会明确提示而不是空白

### 2.2 移动端

已完成：

- 新增 `PoiMapScreen`
- 采集者工作台增加“我的地图”入口
- 核验者工作台增加“空间核验”入口
- 采集者列表增加“地图”入口
- 核验者列表增加“地图”入口
- 采集者详情增加“地图查看”入口
- 核验者详情增加“地图查看”入口
- 移动端地图页支持按分类、状态、区域筛选
- 移动端地图页支持点击点位查看详情摘要

当前说明：

- 移动端采用 `react-native-webview + 高德 JSAPI` 的方式接入高德地图

- 后续如果迁移到原生构建链，可再评估切换到原生地图 SDK

## 3. 角色视角

### 3.1 管理员

管理员在阶段 4 主要关心：

- 整体分布
- 问题点位分布
- 各状态处理进展
- 从地图快速回到详情查看轨迹

### 3.2 核验者

核验者在阶段 4 主要关心：

- 待核验点位在哪里
- 哪些点位已被标错或进入整改复核
- 能否从地图快速进入核验详情
- 能否直接跳转导航辅助现场判断

### 3.3 采集者

采集者在阶段 4 主要关心：

- 自己提交的点位是否有坐标
- 驳回记录在空间上分布如何
- 能否从详情快速回到地图

## 4. 关键实现说明

### 4.1 地图点位语义

- 普通点位：按状态基础色展示
- 问题点位：驳回或存在问题标记时高亮
- 待复核点位：单独保留视觉区分

### 4.2 地图与业务页联动

已打通以下联动：

- 列表 -> 地图
- 详情 -> 地图
- 地图 -> 详情

说明：

- 管理端通过 URL 参数保留筛选和选中点位
- 移动端通过导航参数定位到对应 POI

### 4.3 导航入口

当前已完成：

- 地图详情卡片提供导航入口
- 导航入口使用高德 URI

当前未完成：

- 实时路径规划结果页
- 多路径方案对比
- 步行 / 骑行 / 驾车切换

这些能力已经在页面中预留扩展位。

## 5. 环境变量补充

阶段 4 新增移动端关键变量：

```bash
VITE_AMAP_WEB_KEY=你的高德 Web 端 Key
EXPO_PUBLIC_AMAP_WEB_KEY=你的高德 Web 端 Key
```

说明：

- 该变量建议配置在 `apps/mobile-app/.env`
- `VITE_AMAP_WEB_KEY` 建议配置在根目录 `.env`
- `EXPO_PUBLIC_AMAP_WEB_KEY` 建议配置在 `apps/mobile-app/.env`
- 修改后需要重启 Expo
- 修改管理端 Key 后需要重启 Vite
- 如果未配置，地图页会显示缺少 Key 的明确提示，不会显示高德底图
