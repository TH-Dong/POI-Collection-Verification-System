# 当前功能使用手册

本文档面向当前仓库的演示与联调环境，说明：

- 当前有哪些可用功能
- 不同角色应该登录哪里
- 每个角色如何一步步体验功能
- 当前默认演示账号有哪些

## 1. 当前推荐体验入口

### 管理端 Web

- 地址：`http://localhost:5173`
- 适合角色：`admin`、`verifier`

### 移动端 Expo

- 适合角色：`collector`、`collector2`、`verifier`、`verifier2`
- 推荐从首页依次体验：
  - 任务中心
  - 通知中心
  - 协作会话
  - POI 相关页面

### 后端

- 地址：`http://localhost:8080`
- 健康检查：`/api/v1/auth/health`

## 3. 已准备好的演示数据

后端启动后，系统会自动重置旧业务数据，并重新生成一批阶段 7 演示数据，覆盖：

- 草稿 POI
- 新提交待核验 POI
- 整改后重新提交 POI
- 已通过 POI
- 被驳回整改 POI
- 争议处理中 POI
- 等待最终裁定 POI
- 已最终确认 POI
- 采集任务、核验任务、争议任务、最终裁定任务
- 广播通知、角色通知、任务通知、聊天通知
- 采集者群聊、核验者群聊、POI 私聊

说明：

- 每次重启后端，旧的业务 POI、任务、通知、聊天记录都会被清空并重建为这套演示数据
- 字典、规则、用户和角色不会被清空

## 4. 采集者怎么用

推荐使用 `collector` 或 `collector2` 登录移动端。

### 4.1 首页

进入“工作台”后可直接看到：

- 待处理任务数量
- 高优先级任务数量
- 未读通知数量
- 未读会话数量

### 4.2 我的记录

进入“我的记录”可以看到不同状态的 POI：

- `DRAFT`：可继续编辑
- `REJECTED`：可查看整改意见、继续整改、发起异议
- `SUBMITTED` / `RESUBMITTED`：可查看详情和沟通记录
- `APPROVED` / `FINALIZED`：可查看最终结果和历史

推荐体验：

1. 打开草稿记录，确认可以继续编辑
2. 打开被驳回记录，查看“整改意见”
3. 打开已提交记录，查看“沟通记录”并点击“联系核验者”

### 4.3 任务中心

进入“任务中心”可看到管理员派发的采集补充任务，例如：

- 补采照片
- 补采营业时间
- 整理周边参照物

### 4.4 通知中心

进入“通知中心”可查看：

- 管理员广播通知
- 采集角色专属提醒
- 聊天消息提醒
- 任务提醒

### 4.5 协作会话

进入“协作会话”可看到：

- 采集者群聊
- 与核验者的 POI 私聊

推荐体验：

1. 打开“采集者协作群”
2. 查看历史消息
3. 进入某条 POI 私聊继续沟通

### 4.6 地图

进入“我的地图”可查看：

- 我的点位分布
- 点位状态
- 从地图跳转回详情

### 4.7 异议处理

对于 `REJECTED` 的记录：

1. 进入详情
2. 点击“发起异议”
3. 填写说明
4. 提交后，记录将进入 `DISPUTING`

## 5. 核验者怎么用

推荐：

- Web 端使用 `verifier`
- 移动端使用 `verifier` 或 `verifier2`

### 5.1 管理端 Web

登录后重点看左侧菜单：

- 系统概览
- 任务中心
- 通知中心
- 协作会话
- 待核验列表
- 空间核验
- 争议处理

### 5.2 待核验列表

进入“待核验列表”后可看到：

- 新提交待核验记录
- 整改后重新提交记录

进入详情后可：

- 查看图片、坐标、描述
- 填写错误标记
- 核验通过
- 驳回整改
- 查看沟通留痕
- 直接打开与采集者的私聊

### 5.3 协作会话

进入“协作会话”可看到：

- 核验者群聊
- 与采集者的 POI 私聊

推荐体验：

1. 打开核验者群聊
2. 查看系统准备好的消息
3. 进入某条 POI 私聊
4. 回复采集者
5. 返回 `POI 详情` 查看沟通留痕

兼容路径：

- `http://localhost:5173/chat`
- `http://localhost:5173/conversations`

### 5.4 任务中心

进入“任务中心”可看到：

- `VERIFY` 任务
- `DISPUTE` 任务

当前演示库已准备：

- 新提交核验任务
- 整改复核任务
- 争议处理任务

### 5.5 通知中心

进入“通知中心”可看到：

- 广播通知
- 核验角色提醒
- 任务提醒
- 聊天提醒

### 5.6 争议处理

进入“争议处理”后可查看：

- `DISPUTING`
- `ARBITRATING`
- `FINALIZED`

在争议详情中可：

- 查看采集者说明
- 查看沟通记录
- 补充说明
- 升级管理员最终裁定

### 5.7 移动端核验体验

移动端可体验：

- 待核验队列
- 核验详情
- 协作会话
- 争议处理
- 空间核验地图

## 6. 管理员怎么用

推荐使用 `admin` 登录 Web 端。

### 6.1 系统概览

查看：

- POI 汇总
- 争议汇总
- 任务汇总
- 通知汇总

### 6.2 任务中心

管理员可查看全量任务：

- 采集任务
- 核验任务
- 争议处理任务
- 最终裁定任务

### 6.3 通知中心

管理员可：

- 查看“我的通知”
- 查看群发记录
- 查看通知模板
- 新建群发通知

### 6.4 协作会话

管理员可查看全量会话，并可进入查看消息记录。

### 6.5 处理进展 / 地图进展

管理员可查看：

- 所有 POI 状态流转
- 不同点位的地图分布
- 点位详情
- 沟通留痕

### 6.6 争议处理与最终裁定

管理员可：

- 查看升级到最终裁定的争议
- 进入裁定页
- 提交最终结论

### 6.7 运营配置

管理员可维护：

- POI 分类
- 错误类型
- 流程规则
- 用户角色

## 7. 推荐演示顺序

如果你要完整演示一次当前系统，推荐顺序如下：

1. 用 `collector` 登录移动端，看首页、任务中心、通知中心、协作会话
2. 进入“我的记录”，打开 `REJECTED` 和 `SUBMITTED` 记录
3. 从 `SUBMITTED` 记录中发起与核验者私聊
4. 用 `verifier` 登录 Web 端，进入“协作会话”查看新消息
5. 进入“待核验列表”，查看新提交和整改复核记录
6. 进入“争议处理”，查看 `DISPUTING` 与 `ARBITRATING`
7. 用 `admin` 登录 Web 端，查看任务中心、通知中心、裁定页和运营配置

## 8. 如果你没看到新数据

请检查以下几点：

1. 需要重启后端，初始化器才会重新清空并生成演示数据
2. 如果前端已开着，刷新页面即可重新读取新数据
3. 如果管理端“协作会话”还是 404，请重启 `npm run admin:dev`
4. 如果移动端仍显示旧数据，请重新进入页面，必要时重启 Expo
