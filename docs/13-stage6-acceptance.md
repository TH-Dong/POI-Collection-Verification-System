## 3. 验收路径

### 3.1 任务中心

1. 使用 `admin / 123456` 登录管理端
2. 进入“任务中心”
3. 新建一条采集任务或核验任务
4. 指定负责人、优先级和截止时间
5. 任务应保存成功并可修改状态

### 3.2 自动任务

1. 使用 `collector / 123456` 登录移动端
2. 新建并提交一条 POI
3. 使用管理员登录管理端
4. 在“任务中心”应看到一条新的 `VERIFY` 任务

### 3.3 通知中心

1. 使用管理员在“通知中心”群发一条通知
2. 使用采集者或核验者登录移动端
3. 进入“通知中心”
4. 应能看到新通知并标记已读

### 3.4 运营配置

1. 使用管理员进入“后台运营配置”
2. 修改一个 POI 分类或错误类型
3. 再次进入采集页或核验页
4. 页面应使用最新配置项

## 4. RabbitMQ 说明

`docker-compose.yml` 已增加：

- `rabbitmq`

默认地址：

- AMQP：`localhost:5672`
- 管理台：`http://localhost:15672`

默认账号：

- `guest / guest`

若本地暂不启动 MQ，系统默认仍可通过本地直连方式处理通知逻辑。
